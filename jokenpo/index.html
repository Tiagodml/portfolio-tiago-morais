Sobre o projeto

Este projeto é uma versão web do clássico jogo Pedra, Papel e Tesoura.

O jogador escolhe uma opção e o computador realiza uma escolha aleatória. O JavaScript é responsável pela lógica do jogo e pelo controle do placar.

Tecnologias: HTML5, CSS3 e JavaScript.
